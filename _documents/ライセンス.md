# ライセンス

## 提供条件

本プロジェクトの会社・著作権者・作者の名義は、株式会社ピー・エム・シー ITソリューション事業部とする。
英語表記は `PMC Co., Ltd. IT Solution Div.` とし、.NET の `Company`・`Authors`・`Copyright`、
npm の `author`、`NOTICE` に使用する（2026-10-22 決定）。製品名・名前空間とは区別する。

FeedIngest は **AGPL-3.0-or-later 単独**で提供する。商用ライセンスとのデュアル提供は行わない。
`LICENSE` にライセンス本文、`Directory.Build.props` の `PackageLicenseExpression` と
`package.json` の `license`、`NOTICE` に同じ SPDX 識別子を置く。

## テンプレートからの整理

- デュアル提供への切替手順と、将来の商用再許諾を目的にした規約・リリース条件を削除した
- `LICENSE`、AGPL のメタデータ、第三者表示の `NOTICE` は維持する
- 初期テンプレートに商用条件書・CLA 一式は存在しなかった。
  2026-10-22 の「公開するリポジトリは CLA を足す」というユーザー指示で CLA 一式を導入する。
  `LICENSE-COMMERCIAL.md` などの商用ライセンス文書は追加しない
- `cla-check.yml` を追加するが、GitHub の設定・ルールセットは変更しない。
  `cla` の必須化は初期配置のマージ後に別作業で行う。既存チェックは維持する

## 貢献

貢献コードは本プロジェクトの AGPL-3.0-or-later 条件で受け入れる。
同日の後続ユーザー指示により U7 の「CLA なし」を更新し、取り込み前に CLA への署名を求める。
商用再許諾を含む許諾は、将来のライセンス選択の余地を残すためのもので、現在の提供条件は変えない。
追加のDCO運用は導入しない。貢献者自身が提供できる権利を確認する。
外部コードの著作権表示・ライセンスを削除してよいという意味ではない。
手続きは [貢献のしかた](../CONTRIBUTING.md)、提供条件は [LICENSING.md](../LICENSING.md) を参照する。

### 草案と法務確認

[CLA](../CLA.md) は Template の草案を基にし、第 1・2 節の条文は対象ソフトウェア名以外を変更しない。
正式な同意を受ける前に法務の確認を受け、草案の但し書きを外す。
許諾先は草案どおり「株式会社ビークルビジョン」であり、本プロジェクトの著作権者名義とは異なる。
許諾先・権利者の関係、法人署名者の代表権限と個人用同意の充足、許諾範囲・特許条項の妥当性は法務へ確認する。
指定の署名記録の追加は、法務確認済みであることを意味しない。

参照元: [Template PR #44][template-cla-pr]（2026-10-22 参照）。

## 依存と参照

依存 OSS は AGPL と矛盾しない MIT / BSD 系 / Apache-2.0 を基本とする。
採用前に一次情報のライセンスを確認し、出典・参照日、NOTICE とロックファイルを更新する。
例外はレビュー前に依存へ追加しない。設計上の候補は、導入済みの依存とは分けて記載する。

Core.Data は自社共通部品のAGPL側利用を例外承認済み（同日、U2）。
Data の実装時に追加する。今回Core.Data／Core.Mailは依存に含めない。

Pleasanter 本体は API の事実確認だけに使う参照専用サブモジュール。
AGPL 単独化後も、コピー・流用・リンク・プロジェクト参照・配布物への同梱を禁止する。
`scripts/reference-isolation-check.sh` を維持する。
未公開の DotNetClient（LGPL）は設計の参考のみとし、依存しない。
