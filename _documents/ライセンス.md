# ライセンス

## 提供条件

FeedIngest は **AGPL-3.0-or-later 単独**で提供する。商用ライセンスとのデュアル提供は行わない。
`LICENSE` にライセンス本文、`Directory.Build.props` の `PackageLicenseExpression` と
`package.json` の `license`、`NOTICE` に同じ SPDX 識別子を置く。

## テンプレートからの整理

- デュアル提供への切替手順と、将来の商用再許諾を目的にした規約・リリース条件を削除した
- `LICENSE`、AGPL のメタデータ、第三者表示の `NOTICE` は維持する
- `LICENSING.md`、`LICENSE-COMMERCIAL.md`、`CLA.md`、`.github/cla/`、
  `cla-check.yml` は初期テンプレートに存在しなかったため、削除対象なし・追加もしない
- CI・ルールセットにも CLA 必須チェックは存在しない。ビルド・依存監査・参照隔離のチェックは維持する

## 貢献

貢献コードは本プロジェクトの AGPL-3.0-or-later 条件で受け入れる。
商用再許諾のための CLA は要求しない方針案とする。
貢献者の権利確認・DCO 等の追加要否は、設計メモの未決事項としてレビューする。
外部コードの著作権表示・ライセンスを削除してよいという意味ではない。

## 依存と参照

依存 OSS は AGPL と矛盾しない MIT / BSD 系 / Apache-2.0 を基本とする。
採用前に一次情報のライセンスを確認し、出典・参照日、NOTICE とロックファイルを更新する。
例外はレビュー前に依存へ追加しない。設計上の候補は、導入済みの依存とは分けて記載する。

Pleasanter 本体は API の事実確認だけに使う参照専用サブモジュール。
AGPL 単独化後も、コピー・流用・リンク・プロジェクト参照・配布物への同梱を禁止する。
`scripts/reference-isolation-check.sh` を維持する。
未公開の DotNetClient（LGPL）は設計の参考のみとし、依存しない。
