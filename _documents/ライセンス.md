# ライセンス

## 提供条件

本プロジェクトの会社・著作権者・作者の名義は、株式会社ピー・エム・シー ITソリューション事業部とする。
英語表記は `PMC Co., Ltd. IT Solution Div.` とし、.NET の `Company`・`Authors`・`Copyright`、
npm の `author`、`NOTICE` に使用する（2026-10-22 決定）。製品名・名前空間とは区別する。

FeedIngest は **AGPL-3.0-or-later と商用ライセンスのデュアルライセンス**で提供する（草案。法務の確認前）。
利用者は [LICENSING.md](../LICENSING.md) の A（AGPL）か B（商用。法人向け）を選ぶ。
SPDX 表記は `AGPL-3.0-or-later OR LicenseRef-PMC-Commercial`（`NOTICE`）。
`LICENSE` に AGPL の本文、[LICENSE-COMMERCIAL.md](../LICENSE-COMMERCIAL.md) に商用ライセンスの概要を置く。
`package.json` の `license` は AGPL-3.0-or-later のまま変えない。
`Directory.Build.props` の `PackageLicenseExpression` は、NuGet が `LicenseRef-*` を含む式を受け付けないため持たない。

### 法務へ確認する事項

- 「法人」に含める範囲（営利・非営利・官公庁・教育機関・個人事業主）
- 商用ライセンスの条件（連絡先は `LICENSE-COMMERCIAL.md` に記載済み）
- Core（Core.Data）の商用ライセンスとの関係（まとめて契約するか。Core の著作権者は当社と同じ ITソリューション事業部）
- CLA の文言

## 貢献

貢献は、取り込む前に CLA への署名を求め、AGPL-3.0-or-later と商用ライセンスの両方で提供できるようにする。
2026-10-22 の後続ユーザー指示により U7 の「CLA なし」を更新し、
2026-10-28 のデュアル化の方針で、CLA の再許諾（商用ライセンスを含む）を実際の提供条件に結びつけた。
追加のDCO運用は導入しない。貢献者自身が提供できる権利を確認する。
外部コードの著作権表示・ライセンスを削除してよいという意味ではない。
手続きは [貢献のしかた](../CONTRIBUTING.md)、提供条件は [LICENSING.md](../LICENSING.md) を参照する。

### 草案と法務確認

[CLA](../CLA.md) は Template の草案を基にし、許諾先を Questionnaire の CLA と統一する。
第 1・2 節の権利義務の文言は Questionnaire と同じとする（対象ソフトウェア名・提供ライセンスの位置づけと書式を除く）。
正式な同意を受ける前に法務の確認を受け、草案の但し書きを外す。
許諾先は株式会社ピー・エム・シー ITソリューション事業部（ユーザーの指示 2026-10-22）。
法人署名者の代表権限と個人用同意の充足、商用再許諾を含む許諾範囲・特許条項の妥当性は法務へ確認する。
指定の署名記録の追加は、法務確認済みであることを意味しない。

## 依存と参照

依存 OSS は、商用ライセンスでも提供できる MIT / BSD 系 / Apache-2.0 を基本とする（デュアル化に伴い、AGPL と矛盾しないだけでは足りない）。
コピーレフト系の依存は、商用側を提供できなくなるため、例外としてレビューを経る。
採用前に一次情報のライセンスを確認し、出典・参照日、NOTICE とロックファイルを更新する。
例外はレビュー前に依存へ追加しない。設計上の候補は、導入済みの依存とは分けて記載する。

Core.Data は自社共通部品で、AGPL／商用のデュアル提供。AGPL 側の利用を例外承認済み（2026-10-22、U2）。
2026-10-28 のデュアル化後は、**商用側を選ぶ利用者に Core の商用ライセンスも必要になる**
（Core の著作権者は本製品と同じ ITソリューション事業部）。
商用の条件（Core とまとめて契約するか等）は決めていない。法務へ確認する。
Data の実装時に追加する。今回 Core.Data／Core.Mail は依存に含めない。
Core.Data の追加時は、`scripts/license-check.ps1` の許可ライセンス（寛容ライセンスのみ）の扱いも見直す。

Pleasanter 本体は API の事実確認だけに使う参照専用ソース。
必要時に取得し、Git で追跡しない。CI でも取得しない。
AGPL 単独でもデュアルでも、コピー・流用・リンク・プロジェクト参照・配布物への同梱を禁止する。
取り込むと、本体の著作権が当社にないため、商用側を提供できなくなる。
`scripts/reference-isolation-check.sh` を維持する。
未公開の DotNetClient（LGPL）は設計の参考のみとし、依存しない。
